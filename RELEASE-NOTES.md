# 0.17.0 — Gruppenfassung mit GitHub-Updates

- Unabhängiges Enhancement-Modul für Foundry VTT 14.364 und N5eB 3.1.1.
- Optionale Automationen für Ninjutsu Specialist, Genjutsu Specialist, Medical-Nin und Taijutsu Specialist sowie Chakra-Kosten und unabhängige Dojutsu.
- Dauerhafter Manifest-Link zur Installation und für spätere Foundry-Updates.
- Die Class Mod Library ist keine Voraussetzung. Aktionsökonomie bleibt manuell.

Diese Implementierungsfassung ist noch nicht durch die Gruppe spielgeprüft. Automationen sind standardmäßig deaktiviert und werden gezielt in den Moduleinstellungen eingeschaltet. Bekannte Grenzen und manuelle Abläufe stehen in den jeweiligen Gruppenfassungen und in TESTING.md.

Installation: In Foundrys Setup unter **Add-on Modules → Install Module → Manifest URL** einfügen:

https://github.com/Kirai124/naruto-system-enhancments/releases/latest/download/module.json

Bei einer zuvor manuell installierten Fassung ohne Manifest-Verknüpfung einmal über diesen Link installieren. Danach denselben Link für Updates verwenden. Kein Löschen von Weltdaten erforderlich.
